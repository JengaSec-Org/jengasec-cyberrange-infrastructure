# Scripted scenarios

**Owner:** AIC-A3 (AIC-08, AIC-14) · **Consumed by:** the AI API sandbox (AIC-11), AI Defence cells, SCR

A scenario is a **known-answer event sequence**. AI cells develop against scenarios before live telemetry exists, and scoring compares what an AI cell detected with the answer key.

## Layout

```
scenarios/
  _lib.py               shared helpers: deterministic ids and clock, the event envelope, writing outputs
  _template/            copy this to start a scenario
  <id>-<name>/          e.g. s01-credential-stuffing
    scenario.yaml       what, which cell, ATT&CK IDs, expected detections
    generate.py         writes events.jsonl (telemetry-event.schema.json shape)
    answer-key.yaml     generated by generate.py: which events are malicious, and what a correct detection and response is
    events.jsonl        generated, committed: the AI API sandbox serves it
```

Events are telemetry contract v2, built the way OBS's Vector builds them (`event_id` and `integrity_hash` included). `actor.team_id` / `actor.team_label` follow the address plan and `scripts/ai-teams.yaml`. `python ai-api/scripts/validate-scenarios.py` checks every event against the v2 schema and the event catalogue, and checks that each answer key's malicious events are exactly the `red-*` ones, because the labels are the AI track's ground truth.

Regenerate after any change: `python scenarios/<id>/generate.py --seed 1`, then `python ai-api/scripts/validate-scenarios.py`.

## Rules

- Python standard library plus `requests` and PyYAML (Faker is allowed for data generation only, and is pinned).
- The output validates against `contracts/telemetry-event.schema.json` (v2) and `contracts/telemetry-event-catalogue.yaml` (checked by `ai-api/scripts/validate-scenarios.py`).
- Deterministic: `generate.py --seed 1` produces the same file every time.
